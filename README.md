# FaidaBiz App

Flutter client for **FaidaBiz** — Simple Business Management App.

**Tagline:** Jua Mauzo Yako, Dhibiti Biashara Yako, Ongeza Faida

## Bottom navigation

1. Nyumbani (Home)
2. Mauzo (Sales)
3. Bidhaa (Products)
4. Ripoti (Reports)
5. Mipangilio (Settings)

## Setup

1. Point the app portal URL at the FaidaBiz Laravel server (see WhatsLipa/portal settings — same host).
2. API base used: `{portal}/api/faidabiz`
3. Run:

```bash
flutter pub get
flutter run
```

Default language: **Kiswahili**.

Brand colors: green `#15803D`, white, black.
